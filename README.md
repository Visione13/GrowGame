# Grow Tycoon

Ein kleines Idle/Tycoon-Spiel über den Anbau und Verkauf verschiedener Pflanzensorten, gebaut mit React, Vite und Tailwind CSS.

## Entwicklung

```bash
npm install
npm run dev
```

Die App läuft danach unter [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
```
